# LibTrack – Library Management System

## About the Project
LibTrack is a Java-based Library Management System used to manage books, members, book issuing, book returns, overdue books, and fine calculation.

## Technologies Used
- Java 21
- Java Swing
- MySQL 8.0
- JDBC
- Visual Studio Code

## Features
1. Dashboard
2. Add and View Books
3. Add and View Members
4. Issue Books
5. Return Books
6. Automatic Book Quantity Update
7. Overdue Book Tracking
8. Fine Calculation (₹5 per overdue day)

## Database Tables
- Books
- Members
- IssueRecords
- Returns

## How to Run
1. Install Java and MySQL.
2. Create the LibTrack database and required tables.
3. Add MySQL Connector/J to the project `lib` folder.
4. Open the project in VS Code.
5. Run `Dashboard.java`.
