# LibTrack – Library Management System

## About the Project
LibTrack is a Java-based Library Management System used to manage books, members, book issuing, book returns, overdue books, and fine calculation.

## Technologies Used
- Java 21
- Java Swing
- Spring Boot
- MySQL 8.0
- JDBC
- HTML, CSS, JavaScript
- Visual Studio Code

## Features
1. Dashboard
2. Add and View Books
3. Add and View Members
4. Issue Books
5. Return Books
6. Automatic Book Quantity Update
7. Overdue Book Tracking
8. Fine Calculation (₹5 per overdue day)
9. Web-based frontend
10. REST API backend

## Database Tables
- Books
- Members
- IssueRecords
- Returns

## Project Structure
- `src/` – Java Swing desktop application
- `backend/` – Spring Boot backend and web application
- `web/` – Frontend source files
- `lib/` – MySQL Connector/J
